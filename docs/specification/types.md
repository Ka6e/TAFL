# Семантика типов данных языка Glacier

## Краткое описание

Данный документ описывает семантику типов данных, поддерживаемых языком программирования **Glacier**, а также правила их использования в выражениях, переменных и функциях.

Поддерживаемые типы данных:

* `int` — целочисленный тип
* `float` — вещественный тип
* `string` — строковый тип
* `bool` — логический тип с числовой семантикой
* `void` — отсутствие возвращаемого значения

Язык Glacier является **динамически типизированным**: тип значения определяется во время выполнения. При этом язык поддерживает два вида объявления переменных — с фиксированным типом (`let`) и с динамически изменяемым типом (`var`).

## Литералы

### Целочисленные литералы (`int`)

Тип `int` поддерживает следующие формы литералов:

* десятичные: `0`, `42`, `1_000_000`
* шестнадцатеричные: `0x2A`
* двоичные: `0b101010`

Символ подчёркивания (`_`) может использоваться для улучшения читаемости и не влияет на значение числа.

Тип `float` поддерживает следующие формы литералов:

Вещественные числа поддерживают аналогичные формы записи (10.5, 0.001, 1_000.25).

Символ подчёркивания (`_`) может использоваться для улучшения читаемости и не влияет на значение числа.

### Логические литералы (`bool`)

Поддерживаются два логических литерала:

```glacier
true
false
```

Семантически:

* `false` эквивалентен числу `0`
* `true` эквивалентен числу `1`

### Строковые литералы (`string`)

Поддерживаются следующие виды строковых литералов:

* обычные строки: `"Hello"`
* многострочные строки: `"""Line1\nLine2"""`
* сырые строки: `` `C:\path\file` ``

Строки являются неизменяемыми.

## Операторы

### Арифметические операторы

Арифметические операторы применимы к значениям типа `int` и возвращают значение типа `int`:

* `+`, `-`, `*`, `/`, `%`, `//`, `**`

### Побитовые операторы

Побитовые операторы применимы только к значениям типа `int`:

* `&`, `|`, `^`, `~`

### Операторы сравнения

Операторы сравнения применимы к значениям типа `int` и `string`:

* `==`, `!=`, `<`, `<=`, `>`, `>=`

Результатом операции сравнения является значение типа `bool`.

### Логические операторы

Логические операторы работают с булевой интерпретацией значений:

* `!` — логическое отрицание
* `&&` — логическое «и»
* `||` — логическое «или»

Семантика логических операций:

* значение `0` интерпретируется как `false`
* любое ненулевое значение интерпретируется как `true`
* результат логических операций всегда равен `0` или `1` и имеет тип `bool`

Операторы `&&` и `||` используют вычисление по короткой схеме (short-circuit evaluation).

## Переменные

### Объявление переменных

В Glacier поддерживаются два способа объявления переменных:

#### Объявление константы с фиксированным типом (`let`)

```glacier
let x: int = 10
```
* константа
* тип переменной обязателен
* тип переменной фиксирован и не может изменяться
* присваивание значения другого типа приводит к ошибке времени выполнения
* присваивание значения, после инициализации приводит к ошибке времени выполнения

#### Объявление с динамическим типом (`var`)

```glacier
var x = 10
x = "hello"
```

* тип переменной выводится из значения
* тип может изменяться при последующих присваиваниях

### Присваивание

* let — создаёт константу: значение фиксировано и не может быть изменено после инициализации. Присвоение значения другого типа или попытка изменить значение приведёт к ошибке времени выполнения.

* var — создаёт изменяемую переменную: тип значения может изменяться, и переменную можно переназначать.

## Преобразования типов

На текущем этапе развития языка Glacier:

* не определены неявные преобразования типов
* не определены явные преобразования типов

Любая операция над несовместимыми типами приводит к ошибке времени выполнения.

Булева интерпретация чисел (`0` / ненулевое значение) является частью семантики типа `bool` и не считается преобразованием типов.

## Целочисленный тип `int`

* `int` — знаковое 64-битное целое число
* диапазон значений: от `-2^63` до `2^63 - 1`
* переполнение приводит к ошибке времени выполнения

Поддерживаются арифметические, побитовые и сравнительные операции.

---

## Вещественный тип `float`

* `float` — знаковое 64-битное число с плавающей точкой
* поддерживаются арифмитические операции   

---


## Строковый тип `string`

* `string` — неизменяемая последовательность символов
* кодировка строк: UTF-8
* поддерживается конкатенация строк с помощью оператора `+`
* поддерживается сравнение строк с помощью операторов `==` и `!=`

Операции индексирования и извлечения подстрок не определены на текущем этапе.

---

## Логический тип `bool`

* `bool` — логический тип с числовой семантикой
* допустимые значения представлены целыми числами
* `0` — ложь (`false`)
* любое ненулевое значение — истина (`true`)

Логические операторы возвращают значение типа `bool`.

---

## Пустой тип `void`

* `void` используется как тип возвращаемого значения функций, не возвращающих результат
* значения типа `void` не существуют
* `void` нельзя использовать в выражениях и присваивать переменным

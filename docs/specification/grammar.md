# Сравнительный обзор синтаксиса выражений Golang и Haskell

Этот документ описывает различия в синтаксисе выражений двух языков программирования — Golang и Haskell, с акцентом на числовые типы данных и грамматику выражений.

## 1. Числовые типы данных

| Категория | Golang | Haskell | Комментарий |
|-----------|---------|---------|-------------|
| Целые числа | `int`, `int8`, `int16`, `int32`, `int64`, `uint` и аналоги без знака | `Int`, `Integer` | В Go фиксированные разряды, в Haskell `Integer` — произвольной длины |
| Вещественные числа | `float32`, `float64` | `Float`, `Double` | Аналогично по смыслу, но в Haskell `Float` — менее точный |
| Комплексные числа | `complex64`, `complex128` | `Complex a` (например, `Complex Double`) | В Haskell комплексные числа реализованы как параметрический тип |
| Символьные типы | `rune` (UTF-8 кодовая точка) | `Char` | В обоих языках одиночные символы в `'` |
| Преобразования | Явные (`int(x)`, `float64(x)`) | Универсальные классы типов (`fromIntegral`, `realToFrac`) | В Go типы несовместимы без приведения, в Haskell — полиморфизм классов типов |

**Итог:**
- **Golang** — строго типизированный и требует явных преобразований
- **Haskell** — гибкий, использует type classes (`Num`, `Integral`, `Fractional`) для абстракции числовых операций

---

## 2. Арифметические операторы

| Оператор | Golang | Haskell | Комментарий |
|----------|---------|---------|-------------|
| `+` | Сложение чисел (`int`, `float`, `complex`) | Сложение (`Num a => a -> a -> a`) | Поведение схоже |
| `-` | Вычитание | Вычитание | Унарный и бинарный вариант в обоих |
| `*` | Умножение | Умножение | — |
| `/` | Деление (всегда вещественное для `float`, целое при `int`) | Деление (`Fractional a => a -> a -> a`) | В Haskell `/` только для вещественных |
| `div`, `mod` | — | Целочисленное деление и остаток | В Go это операторы `/` и `%` |
| `%` | Остаток от деления | `mod` (функция) | В Go — оператор, в Haskell — функция |
| `^` | Побитовое XOR (не возведение в степень!) | Возведение в степень (`^`, `^^`, `**`) | Существенное различие |

**Итог:**
- `^` в Go — побитовая операция, в Haskell — арифметическая
- Go различает типы по контексту, Haskell — по классам типов

---

## 3. Приоритет операторов

| Приоритет (высокий → низкий) | Golang | Haskell |
|-------------------------------|---------|---------|
| 1 | `*`, `/`, `%`, `<<`, `>>`, `&`, `&^` | `^`, `^^`, `**` (возведение в степень) |
| 2 | `+`, ``-`, ` | `, `^` |
| 3 | Сравнения (`==`, `<`, `>`, и др.) | `+`, `-` |
| 4 | Логические (`&&`, `` | ` | `) |
| 5 | Присваивание, запятая, скобки | Логические (`&&`, `` | `) |

**Итог:**
- Приоритет в Haskell может быть переопределён пользователем через декларации `infixl`, `infixr`
- В Go — строго фиксирован и не изменяем

---

## 4. Ассоциативность операторов

| Оператор | Golang | Haskell | Комментарий |
|----------|---------|---------|-------------|
| `+`, `-`, `*`, `/` | Левоассоциативные | Левоассоциативные | Совпадают |
| `^` (Go) | Левоассоциативный | — | В Go — XOR |
| `^`, `**` (Haskell) | — | Правоассоциативные | Возведение в степень |
| Пользовательские | Не поддерживаются | Можно объявлять (`infixl`, `infixr`) | Отличие Haskell |

---

## 5. Встроенные функции для чисел

| Категория | Golang | Haskell | Комментарий |
|-----------|---------|---------|-------------|
| Округление | `math.Round`, `math.Floor`, `math.Ceil` | `round`, `floor`, `ceiling` | Сходные |
| Модули | `math.Abs` | `abs` | Одинаково по смыслу |
| Возведение в степень | `math.Pow(x, y)` | `(^)`, `(**)` | В Go — функция, в Haskell — оператор |
| Константы | `math.Pi`, `math.E` | `pi`, `exp 1` | Различие в нейминге |
| Конверсия | `float64(x)` и др. | `fromIntegral`, `realToFrac` | Go требует явных привидений, Haskell — через классы типов |

---

## 6. Прочие особенности синтаксиса выражений

| Особенность | Golang | Haskell |
|-------------|---------|---------|
| Порядок вычислений | Императивный, строго слева направо | Ленивый, по необходимости (lazy evaluation) |
| Побочные эффекты | Разрешены в выражениях | Запрещены — через IO монаду |
| Типизация | Статическая, но не параметрическая | Статическая и полиморфная (type classes) |
| Скобки | Обязательны для явного порядка | Можно избегать, используя аппликацию и `$` |
| Аппликация | Функции вызываются как `f(x)` | Просто `f x` без скобок |
| Лямбда-выражения | `func(x int) int { return x+1 }` | `\x -> x + 1` |

---

## Итоговое сравнение

| Критерий | Golang | Haskell |
|----------|---------|---------|
| Подход к вычислениям | Императивный | Декларативный |
| Типизация | Жёсткая, но конкретная | Абстрактная через классы типов |
| Расширяемость синтаксиса | Нет | Да (пользовательские операторы) |
| Работа с числами | Строго по типу | Обобщённо через `Num`, `Fractional` |
| Приоритет и ассоциативность | Фиксированы | Настраиваемы |

---

## Пример выражений

### Golang
```go
a := 3 + 4*2 - int(math.Pow(2, 3))
b := float64(a) / 3.5
```

### Haskell
```haskell
let a = 3 + 4 * 2 - (2 ^ 3)
let b = fromIntegral a / 3.5
```

---

## Заключение

Golang и Haskell существенно различаются в философии и синтаксисе выражений:

- **Golang** — практичный, с фиксированной грамматикой, строгими типами и простыми операторами
- **Haskell** — формально чистый язык, допускающий определение собственных операторов, гибкую систему типов и ленивые вычисления

Оба языка эффективно работают с числами, но отражают противоположные подходы:
- **Go** — вычисления как процесс
- **Haskell** — вычисления как описание

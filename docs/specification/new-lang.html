Лексическая структура языка Glacier

Этот документ описывает лексическую структуру пользовательского языка Glacier, который сочетает идеи Go, Haskell и OOP. Язык ориентирован на безопасную и читаемую работу с типами, неизменяемыми данными и функциональными выражениями в объектно-ориентированной парадигме.

Пример программы

module Main

import IO

enum DivisionResult {
    Success(value: int)
    Failure(message: string)
}

class Divider {
    let factor: int

    new(f: int) {
        this.factor = f
    }

    func divide(x: int, y: int) -> DivisionResult {
        if y == 0 then
            return DivisionResult.Failure("Cannot divide by zero")
        else
            return DivisionResult.Success(x / y)
    }
}

func main(): void {
    let divider = Divider.new(2)
    let result = divider.divide(10, 0)

    match result {
        case Success(v): print("Quotient: " + show(v))
        case Failure(msg): print("Error: " + msg)
    }
}

Ключевые слова

Список ключевых слов языка Glacier (в алфавитном порядке):

  • class
  • else
  • enum
  • for
  • func
  • if
  • implements
  • import
  • interface
  • let
  • match
  • module
  • new
  • return
  • then
  • type
  • var
  • where
  • true
  • false
  • null
  • int
  • char
  • string
  • float
  • void
  • char

Ключевые слова регистрочувствительные. Например, Let и let — разные идентификаторы, и только let имеет зарезервированное значение.

Идентификаторы

Идентификатор в Glacier может:

  • Начинаться с буквы Unicode или нижнего подчёркивания _
  • Содержать буквы Unicode, цифры (0–9) и нижние подчёркивания _
  • Не может совпадать с ключевым словом

Примеры допустимых идентификаторов

x, factor, _hidden, showValue, Point3D, calc_result

Недопустимые идентификаторы

1value, if, new!, λresult

Операторы

Арифметические

  • + — сложение
  • - — вычитание
  • * — умножение
  • / — деление
  • % — остаток от деления

Логические

  • && — логическое “и”
  • || — логическое “или”
  • ! — логическое “не”

Сравнения

  • ==, !=, <, <=, >, >=

Функциональные и специальные

  • ++ — инкремент
  • -- —дикремент
  • .. — диапазон чисел (1..10)
  • -> — тип функции
  • : — аннотация типа
  • = — присваивание (для var)

Литералы

Числовые

  • Целые: 42, 0x2A, 0b1010, 1_000_000
  • С плавающей точкой: 3.14, ``

Строковые

  • Обычные: "Hello"
  • Многострочные: """Line1\nLine2"""
  • Сырые (raw): `C:\path\file`

Логические и специальные

  • true, false
  • null — отсутствие значения

Прочие лексемы

Лексема Назначение
( ) Группировка выражений, вызовы функций
{ } Блоки кода, тела классов и функций
[ ] Списки, массивы
, Разделитель элементов
; Необязательный разделитель выражений
: Аннотация типа или тег в enum
. Доступ к полю/методу (this.field)

Пробельные символы

Все пробельные символы Unicode допустимы вне лексем и внутри многострочных строк. Отступы не имеют синтаксического значения (как в Go, а не как в Python).

Комментарии

Поддерживаются два вида комментариев:

  • Однострочные:

    // Это комментарий

  • Многострочные:

    /* Комментарий может содержать
   переносы строк */

Специальные токены

  • EndOfFile — конец входного потока
  • Error — токен, обозначающий недопустимую лексему

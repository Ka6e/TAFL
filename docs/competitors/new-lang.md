# Лексическая структура языка Glacier

Этот документ описывает лексическую структуру пользовательского языка Glacier, который сочетает идеи Go, Haskell и OOP. Язык ориентирован на безопасную и читаемую работу с типами, неизменяемыми данными и функциональными выражениями в объектно-ориентированной парадигме.

---

## Пример программы

```glacier
module Main

import IO, Collections

enum Result[T, E] {
  Ok(value: T)
  Err(error: E)
}

class Calculator {
  let factor: Int

  new(f: Int) {
    this.factor = f
  }

  func safeDivide(x: Int, y: Int): Result[Int, String] {
    if y == 0 then
      return Result.Err("division by zero")
    else
      return Result.Ok(x / y)
  }
}

func main(): Void {
  let calc = Calculator.new(3)
  let r = calc.safeDivide(10, 0)

  match r {
    case Ok(v): print("Result: " ++ show(v))
    case Err(e): print("Error: " ++ e)
  }
}
```

## Ключевые слова

Список ключевых слов языка Glacier (в алфавитном порядке):

- `class`
- `else`
- `enum`
- `for`
- `func`
- `if`
- `implements`
- `import`
- `interface`
- `let`
- `match`
- `module`
- `new`
- `return`
- `then`
- `type`
- `var`
- `where`
- `true`
- `false`
- `null`

**Ключевые слова регистрочувствительные.**
Например, `Let` и `let` — разные идентификаторы, и только `let` имеет зарезервированное значение.

## Идентификаторы

Идентификатор в Glacier может:

- Начинаться с буквы Unicode или нижнего подчёркивания `_`
- Содержать буквы Unicode, цифры (`0–9`) и нижние подчёркивания `_`
- Не может совпадать с ключевым словом

### Примеры допустимых идентификаторов
```
x, factor, _hidden, showValue, Point3D, calc_result
```

### Недопустимые идентификаторы
```
1value, if, new!, λresult
```

## Операторы

### Арифметические
- `+` — сложение
- `-` — вычитание
- `*` — умножение
- `/` — деление
- `%` — остаток от деления

### Логические
- `&&` — логическое "и"
- `||` — логическое "или"
- `!` — логическое "не"

### Сравнения
- `==`, `!=`, `<`, `<=`, `>`, `>=`

### Функциональные и специальные
- `++` — конкатенация строк или списков (как в Haskell)
- `..` — диапазон чисел (`1..10`)
- `->` — тип функции (`Int -> String`)
- `:` — аннотация типа
- `=` — присваивание (для `var`)

## Литералы

### Числовые
- **Целые**: `42`, `0x2A`, `0b1010`, `1_000_000`
- **С плавающей точкой**: `3.14`, `6.022e23`

### Строковые
- **Обычные**: `"Hello"`
- **С интерполяцией**: `"Value: ${x}"`
- **Многострочные**: `"""Line1\nLine2"""`
- **Сырые (raw)**: `` `C:\path\file` ``

### Логические и специальные
- `true`, `false`
- `null` — отсутствие значения

## Прочие лексемы

| Лексема | Назначение |
|---------|------------|
| `( )` | Группировка выражений, вызовы функций |
| `{ }` | Блоки кода, тела классов и функций |
| `[ ]` | Списки, массивы |
| `< >` | Объявление дженериков |
| `,` | Разделитель элементов |
| `;` | Необязательный разделитель выражений |
| `:` | Аннотация типа или тег в enum |
| `.` | Доступ к полю/методу (`this.field`) |

---

## Пробельные символы

Все пробельные символы Unicode допустимы вне лексем и внутри многострочных строк.
**Отступы не имеют синтаксического значения** (как в Go, а не как в Python).

## Комментарии

- **Однострочные**:
  ```glacier
  // Это комментарий
  ```

- **Многострочные**:
  ```glacier

     переносы строк */
  ```
